## Weekly Summary

### Week 1 - HTML Fundamentals
In Week 1 it implemented a simple HTML page and the basics of web page structure such as heading, paragraph. PROJECT BRAND NAME: Lab 1 Test. COLOR SCHEME USED: pink, black, soft rose. TYPOGRAPHY USED: default browser sans-serif. DESIGN GOAL: simple beginner HTML page with centered text and basic styling .

### Week 2 - Semantic & Multimedia
In Week 2 implementation it focuses on semantic HTML and multimedia content, using sections, navigation, and embedded media to create a structured and visually appealing Web page. It is also included styling such as gradient background, stick header, and responsive layout to improve the overall presentation. PROJECT BRAND NAME: Spider-Man: Into the Spider-Verse COLOR SCHEME USED: black, red, dark blue, white. TYPOGRAPHY USED: default HTML sans-serif style. DESIGN GOAL: simple movie overview page focused on text, image, and video presentation

### Week 3 - CSS Basics
In Week 3 the implementation is to create a web page using CSS styling to design a homepage. It included a header with navigation, category cards menu items. a "How it works" section and a footer, all style with color, spacing, buttons, and card layouts to make the page visually appealing. PROJECT BRAND NAME: TechSystems Association. COLOR SCHEME USED: orange, red, white, dark brown. TYPOGRAPHY USED: Arial, sans-serif.
DESIGN GOAL: simple, formal student organization webpage with bold, energetic branding and clean section layout.


### Week 4 - JavaScript Basics and DOM Manipulation
In week 4 the implementation is built a small interactive web page using JavaScript and DOM manipulation. It includes live time display, a dark-mode toggle with saved theme preference. a to-do list that adds and removes tasks, a contact form with email validation and a modal pop up, and some simple event-driven interactions to make the page dynamic. PROJECT BRAND NAME: BU SmartLockNgo! COLOR SCHEME USED: warm orange, cream, dark navy, white. TYPOGRAPHY USED: Segoe UI, Tahoma, Geneva, Verdana, sans-serif
DESIGN GOAL: clean, friendly campus storage service website with a modern, organized, user-focused layout

### Week 5 - Javascript Functions and Bootstrap
In week 5 the implementation is created a Bootstrap-based nature-themed landing page with a responsive navigation bar, a slideshow carousel, accordion sections for information, and a footer. It is used a Bootstrap components and custom CSS to build a modern, polished website layout focused on nature in photography and services. PROJECT BRAND NAME: Spider-Verse. COLOR SCHEME USED: black, red, purple, electric blue, white
TYPOGRAPHY USED: Segoe UI, Arial, sans-serif. DESIGN GOAL: bold, cinematic superhero landing page with a dark futuristic comic-book feel

### Week 6 - API & Client Storage
In week 6 the implementation combine the several client-side web features. local storage for saving the name of the user name and preferences, a weather API call using Open Weather Map, a GitHub profile lookup, and an interactive map with geolocation and location search using OpenStreetMap. It also includes theme and language switching, so the page demonstrates both API integration and browser storage in single dynamic website. PROJECT BRAND NAME: MyWeb APIs Lab. COLOR SCHEME USED: teal, dark navy, warm paper, white. TYPOGRAPHY USED: Georgia / Times New Roman serif with Trebuchet MS / Arial sans-serif accents. DESIGN GOAL: clean technical showcase for browser storage and API experiments with a polished lab-style presentation.

### Week 7 - MiniFullStackStarter
In week 7 it implemented a mini full-stack app that connects a frontend directory form to MongoDB database through an Express API. It lets the user add, view, search, and delete people records, with the backend using Mongoose to store name , email and the age in MongoDB and the frontend displaying the data in a styled list. PROJECT BRAND NAME: Gretchela’s Week 7 Mini App. COLOR SCHEME USED: blush pink, berry burgundy, dark plum, cream. TYPOGRAPHY USED: Segoe UI, Arial, sans-serif
DESIGN GOAL: warm, elegant personal people-directory app for organizing and managing contacts in a simple, modern way.
